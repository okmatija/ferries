# Mediterranean Ferries

Accurate 2026 ferry timetables for the Adriatic, Ionian and Aegean — Croatia,
Italy, Slovenia, Montenegro, Albania and Greece — on an interactive map.

**Live: https://okmatija.github.io/ferries/**

Every sailing is transcribed or harvested from the operators' own official 2026
timetables and passes automatic sanity checks (times increase along each route,
implied speeds are physically plausible, validity periods don't overlap). It may
still contain mistakes — always confirm times directly with the operator before
travelling.
