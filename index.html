How reliable is this? Each source timetable is archived byte-for-byte (PDF, HTML or API response) in the repository and its transcription passes automatic checks: times must increase along every route, implied speeds must be physically plausible, validity periods must not overlap, and Croatian public-holiday rules are modelled. The line badge on every schedule row links straight to the official source PDF so you can verify anything yourself. Mistakes are still possible — always confirm with the operator before travelling, and report errors with the GitHub button on the map.
